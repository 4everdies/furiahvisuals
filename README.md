## what is this

Furiah Visuals is a pure visual mod for Minecraft **1.8.9** (Forge), remapped and ready to build.  
It adds high-resolution effects without changing gameplay:

- Target auras
- Hit & kill effects
- Landing impacts
- Trails
- Reworked particles
- 3D weapons
- Item glow
- Ambience & dynamic skies
- Motion blur
- Dynamic-island HUD
- Restyled UI

Everything is client-side only. just visuals.

Works only Forge (1.8.9).

## how to build

1. Clone the repo:
   ```bash
   git clone https://github.com/4everdies/furiahvisuals.git
   ```

2. Build it using Gradle:
   ```bash
   ./gradlew build
   ```

3. Grab the generated `.jar` from `build/libs/` and drop it into your mods folder.

## features

- Fully remapped to Forge 1.8.9
- Clean source ready for development
- All original visual sections preserved
- Compatible with most 1.8.9 setups

## legal stuff

According to the official [Minecraft guidelines](https://help.minecraft.net/hc/en-us/articles/4409139065613-Mods-for-Minecraft-Java-Edition), players are allowed to modify the game with mods.  
This project is a remapped modification for the Java Edition.  
Use it at your own risk on public servers.
